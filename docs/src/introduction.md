# Code Looper Documentation

Code Looper is a pluggable loop engine for coding-agent CLIs (Claude Code, GitHub Copilot CLI,
Codex CLI). It provides configurable iteration behavior, policy-driven orchestration flows,
and structured logging.

Use the navigation on the left to explore:

- **How-to guides** — getting started, workspace setup, troubleshooting
- **Reference** — configuration options, providers, versioning, project management
- **Explanation** — how orchestration works, prompt injection details
- **Design & Architecture** — PRD and Architecture Decision Records
